# How to run,
make an .env and create origin="link"

link will be the autotrader search like:
https://www.autotrader.co.uk/car-search?channel=cars&keywords=johns%20trading&make=&postcode=LE2%20SFT&sort=relevance

the best way to find this is just use autotrader advanced search and use the keywords as the 'traders' brand and make that the env link.
